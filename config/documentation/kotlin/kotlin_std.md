Kotlin Standard Library & Kotlin Development Kit
Version 2.0 API Specification
This document is divided into two sections:

Kotlin Standard Library
The Kotlin Standard Library provides a comprehensive set of tools to make Kotlin programming easier. These APIs are core to the Kotlin language and are essential for general-purpose computing. They are organized into packages whose names start with kotlin.
Kotlin Development Kit (KDK)
The Kotlin Development Kit (KDK) includes additional APIs and tools that may not be present in all implementations of the Kotlin platform. These are organized into packages whose names start with kdk.
